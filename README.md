# develloco.github.io

Devello's website on GitHub Pages: <https://develloco.github.io>

- `app-ads.txt` lists the sellers authorized to sell ads in Devello's apps (Mirror Atelier): Unity LevelPlay / ironSource Ads and Unity Ads. The ad networks check it at the root of the developer website named in the store listings.
- The reseller lists come from the networks: LevelPlay's documentation (ironSource Ads) and the Unity Monetization dashboard (Organization settings → App-ads.txt). They change over time; when a dashboard reports missing sellers, add them here.
